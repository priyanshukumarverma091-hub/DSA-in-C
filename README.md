### `03 // IMPLEMENTATION PROTOCOL`

</div>

Every implementation is an opportunity to understand the underlying logic.

Where applicable, problems are organized around:

```text
[ PROBLEM ]
     ↓
[ UNDERSTANDING ]
     ↓
[ APPROACH ]
     ↓
[ IMPLEMENTATION IN C ]
     ↓
[ COMPLEXITY ANALYSIS ]
```

|:--|:--|
